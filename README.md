# 軍事口譯詞彙學習系統 (Military Vocabulary Learning Platform)

## 📋 專案簡介

這是一個專為軍事口譯面試準備設計的詞彙學習系統，涵蓋陸軍、海軍、空軍及通用軍事術語，支援中英雙向學習。

## 🎯 功能特色

### 1. 詞彙資料庫
- **陸軍領域**: 步兵、裝甲、砲兵、作戰單位等
- **海軍領域**: 艦艇、潛艇、海上作戰、導航等
- **空軍領域**: 戰機、飛彈、空中作戰、航空術語等
- **通用術語**: 軍階、組織架構、戰略戰術、作戰指令等

### 2. 學習模組
- 📚 **詞彙瀏覽**: 分類檢視、搜尋功能、字母排序
- 💡 **閃卡學習**: 中英雙向練習、標記掌握程度
- ✍️ **測驗模式**: 選擇題、填空題、即時評分
- 📊 **進度追蹤**: 學習統計、正確率分析、弱項提示

## 🚀 快速開始

### 安裝與執行

1. Clone 專案到本地:
```bash
git clone <repository-url>
cd MilP
```

2. 直接在瀏覽器中開啟 `index.html`

無需安裝任何依賴，所有資料儲存在瀏覽器本地。

## 📝 使用說明

### 瀏覽詞彙
1. 在主頁面選擇軍種分類
2. 使用搜尋框快速查找詞彙
3. 點擊詞條查看詳細資訊和例句

### 學習模式
1. 選擇學習方向 (中→英 或 英→中)
2. 使用閃卡進行練習
3. 標記已掌握或需複習的詞彙

### 測驗模式
1. 選擇測驗類型和範圍
2. 完成測驗後查看分數
3. 檢視錯誤題目並加入複習清單

## 🎓 學習建議

1. **分階段學習**: 先掌握通用術語，再深入各軍種專業詞彙
2. **定期複習**: 利用系統追蹤弱項，重點加強
3. **情境練習**: 結合例句理解詞彙在實際口譯中的應用
4. **雙向訓練**: 確保中英互譯都能流暢掌握
